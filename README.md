# Daftar

A fast, keyboard-first notebook for macOS on top of a plain folder of markdown files. Alpha.

## Install

1. Download `Daftar-<version>.dmg` from the [latest release](https://github.com/aslkhon/daftar-releases/releases/latest).
2. Open it and drag **Daftar** to **Applications**.
3. Open Daftar once. macOS says it can't check it for malicious software (Daftar isn't notarised by Apple).
4. Open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to Daftar.

Requires macOS 15 Sequoia or later on Apple silicon. Later versions arrive through **Daftar › Check for Updates…**.
